# k0zt3r

**AppSec · инструменты для пентеста · локальные LLM**

Пишу инструменты для безопасности и автоматизации. Экспериментирую с локальными моделями, Linux и электроникой.

### Основные проекты

- **[Caido Plugins](https://github.com/k0zt3r/caido-plugins)** — анализ JavaScript и управление sqlmap прямо из Caido. `TypeScript`
- **[Telegram Persona LLM](https://github.com/k0zt3r/telegram-persona-llm)** — локальный Telegram-бот с QLoRA-дообучением на стиле переписки. `Python · Qwen · Ollama`
- **[Wordcraft Normokontrol](https://github.com/k0zt3r/wordcraft-normokontrol)** — оформление и проверка учебных работ ИрГУПС в DOCX/PDF. `Python`
- **[ESP32](https://github.com/k0zt3r/esp32)** — электроника, датчики, OLED, MQTT и локальная панель управления. `C++ · Python`
- **[Hyprstack для Kali](https://github.com/k0zt3r/hyprstack-shell)** — форк оболочки Hyprland: адаптация сборки, исправления и инструкция для Kali Linux. `QML · C++ · Linux`
